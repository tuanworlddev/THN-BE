# Docker

## Build image

```docker build -t random-video-backend```

## Run container

```docker run -p 8080:8080 random-video-backend```
# Features

* Random user matching

* WebRTC signaling

* User queue system

* Online user count broadcast

* Country API

* Filter API

* Thread-safe WebSocket handling
